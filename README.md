# Mine optimisation

Interactive engineering tools for the mining industry. The first one models **pumped storage in a disused mine shaft**.

| Folder | What it holds |
|---|---|
| [pump-storage-systems/](pump-storage-systems/) | The technical note, and the [requirements and phase plan](pump-storage-systems/docs/requirements-and-phases.md) |
| [site/](site/) | The website: the pumped storage builder (Phase 1). See [site/README.md](site/README.md) |
| [DEMO.md](DEMO.md) | An 8-minute demo script |

```bash
cd site
pnpm install
pnpm dev      # run locally
pnpm check    # every check CI runs
```
